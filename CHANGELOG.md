## [0.1.0] - 2026-09-25

First release of the restructured project.

### Added

- `NameInfo` — parse file names and frame sequences into `filename`, `basename`,
  `dirname`, `name`, `absname`, `pattern`, `padding`, `ext`, `wild_name`,
  `other_pattern` and `template`.
- Support for explicit placeholders (`%04d`, `%d`, `####`, `$F4`, `<UDIM>`,
  `%(UDIM)d`, `u<U>_v<V>`), four-digit frame numbers, UV tiles, view tokens and
  version tokens.
- Compound extension handling (`.exr.gz`, `.exr.bak`, `.bgeo.sc`, `.ass.gz`,
  `.tar.gz`) and `.tx` texture caches.
- `python -m name_info [filenames ...]` — parses the given names, or prints
  every demo input from `name_info.examples.file_names` when called without
  arguments (`--help` lists the usage).
- `src/name_info/examples.py` — the demo/snapshot inputs, deliberately outside
  the public API: the package exports only `NameInfo`.
- Flat layout: implementation in `name_info/name_info.py`, public re-exports and
  `__version__` in `name_info/__init__.py`, `python -m name_info` entry point in
  `name_info/__main__.py`, packaged with `pyproject.toml` (PEP 621, setuptools,
  `include = ["name_info*"]` so that `tests/` is not collected as a package).
- `unittest` suite: per-field snapshots (`tests/fixtures/snapshot.json`), three
  sha256 behaviour digests, focused behaviour tests, and command line tests.
- `tools/regenerate_snapshot.py` — refresh snapshots and print the digests.
- `tools/run_matrix.ps1` — create `.venv37` / `.venv39` / `.venv310` /
  `.venv311`, run the suite in every interpreter, and point each environment's
  `pip.ini` at the Tsinghua mirror so manual installs inside those environments
  work when PyPI is slow (`-IndexUrl ''` keeps the default index).
- `.github/workflows/tests.yml` — CI on Linux, Windows and macOS with Python 3.7
  through 3.14 (22 job combinations), plus a job that builds the wheel, asserts
  that it ships only the package, installs it and runs `python -m name_info`
  from an unrelated directory.
- English and Chinese documentation (`README.md`, `README.zh-CN.md`,
  `docs/parsing-rules.md`, `docs/parsing-rules.zh-CN.md`).
- `LICENSE` (MIT) and the matching `license` field plus classifier in
  `pyproject.toml`.
- `docs/examples.md` / `docs/examples.zh-CN.md` — every demo input next to its
  real output, grouped by feature. Generated by `tools/build_example_docs.py`
  and kept honest by `DocumentationTests`.

### Changed

- Renamed public attributes for clarity: `pattern_num` → `padding`,
  `extra_pattern` → `other_pattern`, and `root` back to `absname`, which
  describes the value better than a path-like term.
- Renamed internals: `VALID_EXTS` → `KNOWN_EXTS`, `_extract_extension` →
  `_split_ext`, `_construct_name` → `_strip_pattern`, `_find_extra_pattern` →
  `_find_other_pattern`, `_make_wild_name` → `_wildcard`, `_pattern_width` →
  `_padding_width`. `_calculate_details` was removed; the padding limit is now
  enforced inside `_padding_width`.
- `NameFormat` and the legacy `absname`/`second_name` aliases are gone — there
  is a single public API.
- Old layout (`name_info.py`, `test_name_info.py`, `name_info_output.txt`,
  `name_info_regression.json` in the project root) replaced by the standard
  layout above. The demo output snapshot is now generated from
  `tests/fixtures/snapshot.json` inside the test suite.
- All comments and docstrings under `name_info/` are English now, and the CLI help
  text is pure ASCII, so `python -m name_info --help` renders correctly on non-CJK
  consoles as well. The rest of the repository keeps its bilingual / Chinese
  documentation.
- Test suite hardening: `other_pattern` joined the snapshot fields, the digests
  hash every field instead of a portable subset, the CLI entry point is now also
  exercised in-process, and the two Windows-only path inputs moved out of the
  snapshot fixture into `PlatformPathTests`. Snapshots and digests are therefore
  byte-identical on Windows and POSIX (verified), which the CI matrix needs in
  order to be green on Linux and macOS.
- README: the mirror-specific install instructions were removed (they only
  matter on slow networks in China) and replaced with a neutral note about the
  local matrix script; the mirror default now lives only in
  `tools/run_matrix.ps1`.
- README: added a "Why: one sequence, many spellings" section that shows
  `d:/a.%04d.exr`, `d:/a.####.exr` and `d:/a.1001.exr` resolving to one sequence
  identity, with the caveat that `template` keeps the spelling it found;
  `test_one_sequence_many_spellings` locks the promise in.
- Fixed `test_one_sequence_many_spellings` and the matching README example:
  they used `d:/a.*`, whose `dirname` is `"d:/"` on Windows but `"d:"` on
  POSIX, so Linux and macOS failed. Examples now use `d:/render/a.*`, and
  `PlatformPathTests.test_drive_root_path` pins the drive-root difference.
- Added `tools/check_posix.py`, which re-runs the suite with `os.path` set to
  `posixpath` so such mistakes are caught before pushing.

### Removed

- The legacy regression fixture and its compatibility mapping layer.
- The `name_info_output.txt` snapshot file.
